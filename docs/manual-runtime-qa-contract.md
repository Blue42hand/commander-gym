`manual_runtime_qa.QAFileHost` is a separately staged guest-only adapter. Nothing runs on import. There is no installation command. `promote_qa` and `recover_qa_closed` require that exact class; passing a production host or subclass is rejected. Services are restricted to nonce-specific `commander-gym-qa-<nonce>-<role>.service` names. The four role units are recorder, sidecar, native and proxy. The adapter writes only `/opt/commander-gym-qa/qa` and uses only its QA Unix lifecycle socket. It never reads an OpenAI credential or delegates an updater.

The sole host operator must independently review and stage a disposable Linux root/systemd guest, with only a loopback NIC and no host shares or production paths. There must be no production policy, qualifications, native recording root or `/run/credentials` mount. These checks are guest isolation observations; they cannot authenticate the outside supervisor or real host free space.
